One letter for the day: Q — for "queueing", a whole day spent standing in lines. A tiny Node program writes that single character to the entry file, guarding the gate itself: exactly one character, an uppercase letter from A to Z. The letter was picked by criteria critique over six rivals: vivid, funny-true, and the sharp non-obvious initial rather than the briefs own example.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
